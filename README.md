# ตรวจความเคลื่อนไหวสินค้า · เวอร์ชัน 2026-11-20.2

หน้าตาใหม่ของแอปนับสต็อกสาขา ใช้ระบบหลังบ้านเดิมทั้งหมด (Google Sheet "Stock Movement Data" และ Apps Script Web App เดิม)

## อัปขึ้น GitHub

1. อัปทุกไฟล์ในโฟลเดอร์นี้ทับ repo `stock-movement` เดิม (ให้ `index.html` อยู่ชั้นบนสุด)
2. ไฟล์ของแอปเก่าที่ไม่มีในชุดนี้ลบได้ หรือจะเก็บไว้ก็ไม่มีผล
3. เครื่องที่เปิดแอปเก่าค้างไว้จะเห็นเวอร์ชันใหม่เองภายในไม่กี่นาที (แอปเช็ก `version.json`)

ไม่ต้องแก้อะไรใน Google Drive, Sheet หรือ Apps Script

## สิ่งที่เหมือนเดิม

- ล็อกอินสาขาและแอดมิน, รหัสผ่านสาขา, รูปโปรไฟล์
- นับคงเหลือ หน่วยใหญ่/หน่วยย่อย, ยอดยกมาอัตโนมัติจากรอบก่อน (ตั้งเองต้องใส่เหตุผล), รับเข้า / โอนออก
- แป้นตัวเลขแบบเครื่องคิดเลข (+ − × และปุ่มคูณหน่วยใหญ่)
- งานค้างข้ามเครื่อง, ส่งยอดขึ้น Sheet (แท็บละสาขา + สรุปรวม)
- วิเคราะห์ (การ์ด / ตารางย้อนหลัง), เทียบสาขา + เกรด, ย้อนหลัง + รายงาน PDF
- หน้าแอดมิน: ลิงก์ Web App, จัดการสาขา, จัดการแอดมิน
- ข้อมูลที่เครื่องเดิมเก็บไว้ใช้ต่อได้ทันที

## สิ่งที่เปลี่ยน

- หน้าตาใหม่ทั้งหมด รองรับโหมดมืดตามเครื่อง
- นับรายวันอย่างเดียว (รอบรายสัปดาห์เก่ายังดูในย้อนหลังและวิเคราะห์ได้)
- ปุ่ม ‹ › เลื่อนวันบนหัวแอป
- รายการที่นับแล้วย่อเหลือบรรทัดเดียว และมีตัวกรอง ทั้งหมด / ยังไม่นับ / ต้องตรวจ / นับแล้ว
- ช่องรับเข้า/โอนออกซ่อนไว้จนกดเปิด (เปิดค้างเองถ้ามียอด)
- ปุ่ม "ส่งขึ้น Sheet" อยู่แถบล่างตลอดในหน้านับ
- โปรไฟล์และเปลี่ยนรหัสผ่านของสาขาย้ายไปที่ปุ่มรหัสสาขาบนหัวแอป
- ยอดขายแสดง 7 วันล่าสุด
- **ความปลอดภัย:** เอารหัสแอดมินที่เคยฝังในโค้ดหน้าเว็บ และข้อความ "บัญชีสำหรับทดลอง" ออก แอดมินล็อกอินผ่านชีต "แอดมิน" เท่านั้น

## โครงสร้างไฟล์

```
index.html            หน้าแอป + ชุดไอคอน
css/styles.css        สีและสไตล์
js/logic.js           ตรรกะเดิมของแอป (คำนวณ, ส่ง Sheet, ล็อกอิน ฯลฯ)
js/app.js             หน้าตาใหม่
js/dc.js              ตัวเชื่อมตรรกะกับหน้าตา
version.json          เลขเวอร์ชันสำหรับแจ้งอัปเดต
manifest.json, icon-*.png, icons/   ไอคอนและการติดตั้งบนหน้าจอหลัก
```

ถ้าจะแก้รายการสินค้า แก้ `ITEMS` ใน `js/logic.js` แล้วเปลี่ยนเลขใน `version.json` และใน `js/logic.js` (APP_VERSION, appVersion) ให้ตรงกัน
