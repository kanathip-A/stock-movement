# ตรวจความเคลื่อนไหวสินค้า (Stock Movement)

แอปนับสต็อกประจำวันของสาขา ใช้บนมือถือ เทียบการใช้สินค้ากับยอดขาย แล้วเตือนรายการที่ใช้ผิดปกติ

## ใช้งาน

1. **นับสินค้า:** กด + / − หรือแตะตัวเลขเพื่อพิมพ์ แยกหน่วยใหญ่ (ลัง, กระสอบ) กับหน่วยย่อย (แพค, ชิ้น) รายการที่นับแล้วจะย่อเหลือบรรทัดเดียว แตะเพื่อแก้ได้
2. **ยอดขาย:** กรอกยอดขายรวมทั้งวันจาก POS
3. **วิเคราะห์:** แอปคำนวณการใช้ต่อยอดขาย 1,000 บาท เทียบกับอัตราปกติ ถ้าเบี่ยงเกิน 10% จะขึ้นเตือน
4. **ส่งไฟล์:** ดาวน์โหลดไฟล์ CSV (เปิดด้วย Excel ได้) หรือกดแชร์แล้วเลือก Google Drive บนมือถือ

- ยอดยกมาของแต่ละวันจะดึงจากยอดคงเหลือที่นับเมื่อวานให้อัตโนมัติ (แก้ได้)
- ข้อมูลแยกตามสาขาและวันที่ เก็บไว้ในเบราว์เซอร์ของเครื่องนั้น ใช้แบบออฟไลน์ได้
- ถ้าเปลี่ยนเครื่อง ให้กด "ไฟล์สำรอง" ในแท็บส่งไฟล์ แล้ว "กู้คืน" บนเครื่องใหม่

## อัปขึ้น GitHub Pages

1. อัปไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (เช่น `stock-movement`) โดยให้ `index.html` อยู่ที่ root
2. ไปที่ **Settings → Pages** เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอประมาณ 1 นาที แอปจะเปิดได้ที่ `https://<username>.github.io/stock-movement/`
4. บนมือถือ เปิดลิงก์แล้วเลือก "เพิ่มลงหน้าจอหลัก" เพื่อใช้เหมือนแอป

ถ้าอัปเดตไฟล์แล้วมือถือยังเห็นของเก่า ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `stockmove-v4-2`) แล้วอัปอีกครั้ง

## แก้รายการสินค้า สาขา และเกณฑ์เตือน

ทั้งหมดอยู่ใน `js/data.js`

- `ITEMS`: รายการสินค้า (`sys` = ยอดยกมาตั้งต้นเป็นหน่วยย่อย, `bigSize` = หน่วยย่อยต่อ 1 หน่วยใหญ่, `rate` = อัตราใช้ปกติต่อยอดขาย 1,000 บาท)
- `BRANCHES`: รหัสสาขา
- `THRESHOLD`: % ที่ถือว่าผิดปกติ (ค่าเริ่มต้น 10)

## โครงสร้างไฟล์

```
index.html              หน้าแอป + ชุดไอคอน
css/styles.css          สีและสไตล์ (โหมดสว่าง/มืดตามเครื่อง)
js/app.js               การทำงานของแอป
js/data.js              รายการสินค้า สาขา เกณฑ์
manifest.webmanifest    ตั้งค่าติดตั้งบนหน้าจอหลัก
sw.js                   แคชให้ใช้ออฟไลน์ได้
icons/                  ไอคอนแอปและภาพประกอบ
.nojekyll               ให้ GitHub Pages เสิร์ฟไฟล์ตรงตามที่อัป
```
